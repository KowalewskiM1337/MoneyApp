# MoneyApp

Temat: Aplikacja ma ułatwiać rozliczanie się między użytkownikami. Przykładowo po wspólnym wyjściu np. na miasto, jeden użytkownik może utworzyć grupę,
po czym dodać do niej swoich znajomych i ustalić kto, komu i ile powinien oddać pięniędzy za wyjście. Celem jest prosta i intuicyjna aplikacja.

Zespół: Michał Kowalewski (KowalewskiM1337), Martyna Oleszczuk (@hisumii)

Podział: - Michał : Szata graficzna (HTML + CSS), Backend (JavaScript) - Martyna : Backend (JavaScript + React)

Technologia: - HTML + CSS - JavaScript + React

Funkcje:

- Co robi użytkownik:
  -- Tworzy grupę, wpisuje i dodaje użytkowników, decyduje kto, komu i ile ma oddać, dodaje tytuł(opcjonalnie), zapisuje rozliczenie, usuwa grupę
